# Contributing

Issues and pull requests are welcome.

- This is the web version of the [Randomatizer Android app](https://github.com/jamesmyatt/randomatizer). New features go into the Android app first, then get ported here. Changes specific to the web platform are welcome here directly.
- Setup, build and testing: see [DEVELOPING.md](DEVELOPING.md).
- Keep the principles in the [README](README.md): client-side only, no tracking, FOSS dependencies only.
- Run `npm run format && npm run lint && npm run check && npm test && npm run test:e2e` before opening a PR.
- Use American English in strings and docs.

By contributing you agree your work is licensed under Apache-2.0.
